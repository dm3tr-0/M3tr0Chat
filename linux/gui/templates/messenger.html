Анонимный мессенджер через Tor

M3tr0Chat

Децентрализованный мессенджер с архитектурой «пользователь-пользователь». Весь трафик маршрутизируется через сеть Tor, нет центральных серверов, переписки хранятся только локально.

Текущие возможности

✉️

Отправка сообщений

Отправка текстовых сообщений через .onion-адреса с автоматическим созданием временного onion-сервиса при запуске.

🌉

Работа через мосты

Поддержка мостов Tor (obfs4/snowflake) для обхода блокировок в странах с цензурой интернета.

💻

Кроссплатформенность

Основа приложения работает на Windows, Linux и macOS с возможностью компиляции в нативный бинарник.

🎨

CLI-интерфейс

Цветной консольный интерфейс с индикацией статусов и удобной навигацией.

Ограничения

🔴

Онлайн одновременно

Оба собеседника должны быть онлайн одновременно для обмена сообщениями.

🔴

Нет звонков

Нет звонков и видеозвонков из-за низкой скорости сети Tor.

🔴

Нет групповых чатов

В текущей версии отсутствует поддержка групповых чатов.

🔴

Долгий первый запуск

Первый запуск занимает несколько минут из-за инициализации Tor и загрузки дескрипторов.

🔴

Пароль не восстанавливается

При потере пароля восстановить переписки невозможно — это особенность шифрования.

🔴

Требуются мосты

В России и других странах с блокировками требуется настройка мостов Tor для работы.

Работа в России

Для обхода блокировок требуется использовать мосты Tor. Получите актуальные мосты через @GetBridgesBot и укажите их в настройках приложения.

💡 Рекомендуется периодически обновлять мосты. Альтернативный способ — сидеть через впн-провайдера без серверов в РФ и низкой популярностью.
