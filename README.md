#анонимный мессенджер

##Сборка

###Создание окружения
```
python -m venv venv
```
###Активация окружения
```
/venv/Scripts/Activate.ps1
```
###Установка зависимостей
```
pip install requirements
```
###Компиляция в exe
```
pyinstaller --onefile --hidden-import=stem --hidden-import=flask --hidden-import=colorama --hidden-import=requests --hidden-import=pysocks --hidden-import=urllib3.contrib.socks --hidden-import=requests.packages.urllib3.contrib.socks --version-file=version_info.txt --add-data "app.manifest;." --icon=icon.ico m3tr0chat.py
```
###Итоговый результат будет таким:

возможности:
-добавление в друзья/черный список
-отправка текста и картинок/видео
-полная кастомизация интерфейса (пользователю будут необходимы знания css)
-автоматическое обновление приложения(постараюсь реализовать, но это в самую последнюю очередь)

безопасность:
-траффик идет через тор
-нет серверов, переписки хранятся локально
-переписки защищены поверх всего еще и сквозным шифрованием
-при скриншоте/записи экрана окно мессенджера не будет отображаться
-все данные зашифрованы локально(хэш+соль) (нужно будет ввести пароль для входа в приложение, пароль задается пользователем при первом запуске)
постараюсь сделать приложение реверсоустойчивым, чтобы никак нельзя было получить доступ к локальным данным без пароля

минусы:
-для общения нужно чтобы оба участника были онлайн
-нет звонков/видеозвонков(их можно добавить, но ввиду маленькой скорости будут задержки)
-нет группового чата
-первый запуск приложения будет достаточно долгим
-при потере пароля придется распрощаться со своими переписками и контактами, потому что его никак не восстановить
-пока приложение только для Windows 10/11
-для работы приложения в России необходимы мосты(периодически пользователю самому придется находить валидные мосты и в настройках их указывать, но эта проблема решится, как только реализую автоматическое обновление), либо использовать запрещенную технологию из трех букв.
(предпочтительнее использовать второй вариант, причем в идеале у поставщика этой услуги не должно быть серверов в нашей стране, и он не должен быть популярным)
